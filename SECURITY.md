# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | ✅ Active development |

## Reporting a vulnerability

If you discover a security issue in SentinelAI:

1. **Do not** open a public GitHub issue for exploitable vulnerabilities.
2. Contact the repository owner **DjSergio88** via GitHub private security advisories (preferred) or a private channel they designate.
3. Include: affected component, reproduction steps on a test system, impact assessment, and any suggested fix.

## Product security principles

- Defensive functionality only
- Least privilege by default
- No credential theft, keylogging, spyware, stealth persistence, or security bypasses
- No disabling of Windows Defender, firewall, or OS security controls
- Secrets never committed to git (use environment variables / secret managers)
- Honest capability reporting (no fake VPN/TI/AI claims)

## Safe testing

Use only harmless simulated indicators. Never commit or distribute real malware samples.
